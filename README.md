# ParentCircle (Expo React Native)

A polished MVP mobile app for single parents, implemented from the PRD with mock data and scalable architecture.

## Stack
- Expo + React Native
- React Navigation (stack + bottom tabs)
- Zustand state management
- NativeWind styling
- Supabase client scaffold (for future API wiring)

## Implemented Screens
1. Splash / Welcome
2. Onboarding (about you, child age, interests)
3. Home Feed
4. Parent Matching
5. Circles
6. Direct Messaging
7. Local Resources Map
8. User Profile

## Run
```bash
npm install
npm run start
```
